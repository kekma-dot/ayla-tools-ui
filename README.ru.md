# Ayla UI

Редактор ввода с рамкой, компактный футер, выбор модели и локальная панель сессии для [Pi](https://pi.dev). Работает самостоятельно; для компактного вывода инструментов можно добавить [Ayla Compact](https://github.com/kekma-dot/ayla-tools-compact).

## Установка

Нужны Node.js 22.19+ и Pi. Проверенная версия Pi: 1.3.0. Пакет пока в бете.

В терминале:

```bash
pi install git:github.com/kekma-dot/ayla-tools-ui
```

После установки перезапустите Pi. Пакет устанавливается из Git, в npm он не опубликован.

## Использование

Редактор и футер появляются автоматически в интерактивном Pi. Редактор показывает текущую модель, уровень рассуждений и заполнение контекста, когда эти данные доступны. Обычный ввод, многострочное редактирование и автодополнение остаются штатными.

Внутри Pi:

```text
/ayla-ui
/ayla-model
/ayla-footer status
```

Tab в пустой строке тоже открывает панель сессии. Клавиши `1`/`2`/`3` переключают вкладки сессии, моделей и инструментов, `r` обновляет данные, Escape закрывает панель. Команда `/ayla-footer auto|always|never` управляет дополнительной строкой статусов футера в текущей сессии.

Панель показывает локальные сведения о сессии. В выборе модели доступны модели из вашей конфигурации Pi: пакет не добавляет провайдеров и не предоставляет авторизацию. Встроенная команда `/model` и горячие клавиши выбора модели продолжают работать.

## Выбор компонентов

Редактор и футер занимают общие поверхности интерфейса Pi. Если другое расширение уже установило свой редактор, Ayla его сохраняет. Выбор футера зависит от порядка загрузки расширений: выберите один футер, они не объединяются автоматически.

Чтобы оставить только выбор модели, замените запись пакета в `settings.json` каталога агента Pi:

```json
{
  "packages": [
    {
      "source": "git:github.com/kekma-dot/ayla-tools-ui",
      "extensions": ["-extensions/editor.ts", "-extensions/footer.ts"]
    }
  ]
}
```

Добавьте запись в существующий список `packages`, сохранив остальные пакеты. Значение `"extensions": []` отключает все компоненты Ayla UI. После изменения ресурсов перезапустите Pi.

Не подключайте пакет одновременно с другой копией того же редактора или футера Ayla.

## Данные и совместимость

Ayla UI читает доступные внутри Pi метаданные сессии и моделей и отображает их локально. Пакет не выполняет сетевых запросов, не запускает сервисов и не записывает конфигурацию. Выбор модели меняет активную модель в Pi по вашему запросу; следующие сообщения обрабатываются выбранным провайдером как обычно.

Терминальные компоненты работают только в интерактивном TUI. В режимах RPC, JSON и print терминальный интерфейс не подключается. Windows пока не проверена. Персональный backend и другие пакеты Ayla не нужны.

Баннер является иллюстрацией, а не снимком интерфейса. Код распространяется по [MIT](LICENSE); уведомления о включённом коде находятся в [THIRD-PARTY-NOTICES](THIRD-PARTY-NOTICES).

## Удаление

```bash
pi remove git:github.com/kekma-dot/ayla-tools-ui
```

Перезапустите Pi, чтобы вернуть обычный редактор и футер.
